# 🎮 Game Store React

A simple game store landing page built with React, Bootstrap, and Swiper.

## Tech Stack

- **React** 19
- **Bootstrap** 5
- **Swiper** — for game carousel/slider
- **Bootstrap Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm start
```

App will open at [http://localhost:3000](http://localhost:3000).

## Project Structure

```
src/
├── components/   # Reusable UI components (GameCard, GameSwiper, SideMenu, etc.)
├── pages/        # Page layouts (Home, Header, Main)
├── data/         # Static data
└── images/       # Image assets
```

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start dev server |
| `npm run build` | Build for production |
